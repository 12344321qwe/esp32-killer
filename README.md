# ⚡ ESP Killer

**ESP Killer** - портативный автономный инструмент для аудита безопасности и стресс-тестирования беспроводных сетей. Устройство спроектировано на базе мощного двухъядерного микроконтроллера **ESP32-S3-WROOM** и объединяет в себе ключевые радиочастотные трансиверы и модули перехвата данных.

## 🛠️ Аппаратная архитектура и модули

* **Ядро:** ESP32-S3-WROOM (с поддержкой аппаратного USB для BadUSB, Wi-Fi и Bluetooth)
* **Sub-1GHz радио:** CC1101 (анализ и перехват сигналов на частотах 315/433/868 МГц)
* **2.4GHz радио:** NRF24L01 (аудит беспроводных мышей, клавиатур и nRF-сетей)
* **Дисплей:** Одноцветный OLED 0.96" I2C
* **Инфракрасный интерфейс (ИК):** Приемник TSOP + мощный ИК-светодиод (ИК-пушка)
* **Периферия расширения:** Выведены пустые пины (посадочное место) под модуль NFC/RFID HW-868 (RC522 Mini)
* **Интерфейс управления:** 5 тактовых кнопок для навигации по меню

## ⚡ Питание и Коммуникация

* **Интегрированная зарядка:** Схема контроллера заряда распаяна прямо на плате устройства.
* **Многофункциональный USB Type-C:** Служит одновременно для быстрой зарядки аккумулятора, прошивки контроллера ESP32-S3 и аппаратной эмуляции клавиатуры/мыши в режиме **BadUSB**.
* **Хардварный выключатель:** Механический тумблер полностью обесточивает схему, исключая саморазряд батареи.

## 💀 Функционал и возможности взлома

Прибор ориентирован на исследование уязвимостей в пяти основных диапазонах:
1. **Wi-Fi / Bluetooth:** Стресс-тестирование точек доступа, Beacon-спам, аудит BLE-устройств.
2. **Sub-1GHz (CC1101):** Перехват, анализ и воспроизведение сигналов простых шлагбаумов, ворот и систем автоматизации.
3. **2.4GHz (NRF24L01):** Тестирование уязвимостей беспроводной периферии (MouseJack атаки).
4. **Инфракрасный диапазон (ИК):** Запись сигналов пультов и работа в режиме универсального пульта/глушилки телевизоров и кондиционеров.
5. **BadUSB:** Выполнение кастомных скриптов (Ducky Script) при подключении к ПК через штатный Type-C порт.

## 📦 Структура репозитория

Проект разделен на логические папки для удобства сборки, заказа и программирования:

* `/Hardware/Projects/` — Исходные рабочие файлы проектирования из Altium Designer:
  * Файл схемы платы (`.SchDoc`) - полная принципиальная электрическая схема.
  * Файл трассировки (`.PcbDoc`) - разводка дорожек, полигонов и посадочных мест компонентов.
* `/Hardware/Production/` - Промышленные файлы для производства. Папка содержит два варианта Gerber-архивов:
  * `ESP_Killer_Single.zip` - Чертежи единичной платы (размеры 68.5 x 28 мм).
  * `ESP_Killer_Panel_2x2.zip` - Мультипанель, объединяющая 4 платы в один лист 100х100 мм с разделительными линиями.
* `/Hardware/Assembly/` - Руководство по сборке и спецификации:
  * Интерактивный **BOM-файл (Bill of Materials)** - полный список для закупки компонентов с указанием номиналов и типов корпусов.
  * Карты сборки (**Assembly Drawings / Интерактивный перечень**) - визуальные схемы, показывающие, какой именно компонент на каком месте на плате должен стоять, где его ключ и полярность (для диодов, чипов и конденсаторов).
* `/Media/` - Визуализация проекта ESP Killer:
  * `/Media/2D/` - Двухмерные чертежи слоев платы, трассировки и маски.
  * `/Media/3D/` - Рендеры трехмерной модели устройства из САПР для оценки габаритов корпуса.
  * `/Media/Real/` - Фотографии и видео готового устройства в реальности после фабричного изготовления и ручной сборки.
* `/Software/` - Исходный код C++ для компиляции и прошивки девайса через Arduino IDE.

## 💰 Экономия при заказе (Лайфхак с панелью)

Поскольку большинство фабрик прототипирования (включая JLCPCB) предлагают минимальный базовый тариф (\$2) на платы размером до **100х100 мм**, заказывать единичную микро-плату (68.5 х 28 мм) экономически невыгодно - цена падать ниже не будет.

Для максимальной выгоды рекомендуется загружать на сайт завода архив **`ESP_Killer_Panel_2x2.zip`**. Вы получите панель, которая идеально укладывается в рамки 100х100 мм. В итоге за ту же стоимость минимального заказа фабрика пришлет вам **в 4 раза больше готовых плат**! После получения платы легко разделяются по линиям надрезов. Если вам нужна строго одна тестовая плата (например, для локального фрезерования на ЧПУ-станке), используйте архив `ESP_Killer_Single.zip`.
